Colofón

Zasqua es una plataforma de consulta de materiales de archivo desarrollada por Neogranadina y el Laboratorio de Archivos, Memoria y Preservación (AMPL) de la Universidad de California, Santa Bárbara.

Archivos representados

Zasqua reúne materiales digitalizados de cinco instituciones aliadas en Colombia y Perú:

  • Archivo Histórico de Rionegro — Rionegro, Colombia
  • Archivo Histórico Regional de Boyacá — Tunja, Colombia
  • Archivo Histórico del Juzgado del Circuito de Istmina — Istmina, Colombia
  • Centro de Investigaciones Históricas José María Arboleda Llorente, Universidad del Cauca — Popayán, Colombia
  • Biblioteca Nacional del Perú — Lima, Perú

Tecnología

Zasqua es un sitio estático alojado en Cloudflare. Cada página HTML se genera al momento de la publicación; no hay procesos de servidor en ejecución. Esta arquitectura se alinea con los principios de minimal computing — sostenibilidad, portabilidad y resiliencia a largo plazo.

  • Generador de sitio estático: Hugo (Extended 0.160)
  • Búsqueda en el navegador del usuario: Pagefind v1.5.2 — tres índices independientes para descripciones, entidades y lugares
  • Mapas: MapLibre GL JS con mapa base de MapTiler
  • Visor de imágenes: TIFY — visor IIIF con visualización de zoom profundo; imágenes servidas como mosaicos estáticos IIIF Level 0
  • Estilos: Tailwind CSS v4
  • Alojamiento: Cloudflare Workers + Cloudflare R2
  • Almacenamiento de exportaciones: Backblaze B2
  • Integración continua: GitHub Actions mediante Ubicloud

El código de este sitio está disponible en github.com/neogranadina/zasqua. Las exportaciones de datos provienen del backend Django, disponible en github.com/neogranadina/zasqua-backend.

Accesibilidad

Con Zasqua buscamos que cualquier persona pueda consultar el archivo sin barreras. Empleamos HTML semántico, navegación completa por teclado y etiquetas ARIA cuando la estructura HTML no describe por sí sola la función del elemento. Aún no hemos realizado una auditoría formal de accesibilidad; si encuentra una barrera, escríbanos a contacto@neogranadina.org o abra un issue en GitHub.

Privacidad y datos

Zasqua no utiliza cookies ni almacena información personal. El sitio emplea Cloudflare Web Analytics para recopilar estadísticas agregadas de uso — esta herramienta no utiliza cookies, no crea identificadores únicos del navegador y no comparte datos con terceros.

Las búsquedas se ejecutan localmente en su navegador (motor Pagefind en WebAssembly); ninguna consulta se envía a nuestros servidores. Los registros de acceso del CDN se conservan únicamente con fines operativos, en forma agregada.

Licencia

El código de este sitio se publica bajo la licencia AGPL-3.0. Las descripciones archivísticas, los metadatos y las imágenes digitalizadas se publican bajo las condiciones específicas de cada archivo aliado — consulte la sección “Condiciones de reproducción” de cada descripción.
